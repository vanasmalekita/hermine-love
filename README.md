# Hermine, mon infini ❤️
Ouvre simplement `index.html` dans un navigateur — aucun serveur requis.

## Ajouter une musique
1. Copie ton fichier dans `assets/music/` (ex. `notre-chanson.mp3`).
2. Dans `js/script.js`, renseigne `CONFIG.musicSrc: 'assets/music/notre-chanson.mp3'`.

## Personnaliser
- Textes : `index.html` (et les tableaux de phrases dans `js/script.js`).
- Couleurs : variables `:root` en haut de `css/style.css`.
- Les polices viennent de Google Fonts (connexion requise ; polices de secours incluses hors ligne).
- Les animations sont réduites si l'appareil demande `prefers-reduced-motion`.
